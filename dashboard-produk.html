Tambah Produk

Kosongkan jika stok tidak dilacak — tidak ada keterangan apa pun yang muncul di katalog. Isi 0 jika stok habis: produk tetap tampil, tapi diberi label “Stok habis”.

Maks 2MB. Format: JPG, PNG, atau WebP.

Upload ZIP (Bulk)

Siapkan 1 file ZIP berisi file produk.csv (nama file wajib persis itu) dan gambar-gambar produk, semua di root ZIP (tidak di dalam folder). Kolom CSV wajib: nama_produk,kategori,harga,deskripsi,link_shopee,link_tokopedia,link_grab,link_gofood,nama_file_gambar. Kategori harus salah satu dari: Kriya, Tekstil, Kuliner, Mebel, Pertanian, Jasa, Lainnya. Nama file gambar di kolom nama_file_gambar harus persis sama dengan nama file gambar di dalam ZIP. Maks 2MB per gambar, format JPG/PNG/WebP. Harga harus angka bulat tanpa titik atau koma (misal 10000, bukan 10.000).
